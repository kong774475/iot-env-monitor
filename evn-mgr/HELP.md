# 模板项目

### 作者：原炜斌 微信：ywb_1978
本项目由粤嵌科技有限公司开发，生成基于SpringBoot框架IDEA项目的代码，包含以下模块。
 * 常用MVC结构代码生成模块
 * MyBatis xml代码生成模块
 * IDEA项目配置文件生成模块
 * 自定义工具类代码生成模块
   * 文件上传下载工具类
   * 后端校验工具类
   * 日期转换工具类
   * 密码加密工具类（shiro）
   * 项目常量工具类
   * Controller返回模型封装类
 * Web端代码生成模块(完整web页面代码生成功能待开发中)
   * index.html
   * test 请求会访问数据库并在页面打印密码：123 的密文字符串
